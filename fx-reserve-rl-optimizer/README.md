# FX Reserve Portfolio Optimizer using Deep Reinforcement Learning

A research and educational prototype for **stylised foreign-exchange reserve portfolio optimisation** using constrained deep reinforcement learning and transparent portfolio benchmarks.

The project is designed as a central-bank-style decision-support application. It focuses on the classic reserve-management objectives of **safety, liquidity, and return**, rather than speculative trading.

## Project question

Can a constrained reinforcement-learning allocation rule dynamically allocate a stylised reserve portfolio across public market
